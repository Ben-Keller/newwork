# V1 archive

This folder preserves the public site from deployment
[`33130567979`](https://github.com/Ben-Keller/newwork/actions/runs/33130567979),
commit `d5da0e5aefd65ca576a8b09c6355f09fd0a82bb9`.

`snapshot/` contains original published pages/bundles and the deployed commit's
public assets. `manifest.json` records their provenance and checksums. Keep these
inputs unchanged. The Pages build performs URL relocation only in its generated
output, and neither needs V2 assets nor rebuilds V1 against current CMS content.

See [the hosting guide](../../hosting/README.md) for build, preview, and removal.
